# Login Authentication System

## About
A front-end registration and login system
with a protected dashboard.

## Features
- User registration and login
- Password validation
- Duplicate account checking
- Dashboard access checking
- Logout functionality
- Password hashing

## Technologies Used
- HTML
- CSS
- JavaScript
- localStorage
- Web Crypto API

## How to Run
Open register.html in a modern web browser.
Register an account, log in, and test the dashboard.
